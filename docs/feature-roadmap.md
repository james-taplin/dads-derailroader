# Current scope and validation

The application converts Railroader's 21 stock steam locomotives into Derail Valley Custom Car Loader packs. It reads source files from the local Railroader installation, records evidence for generated values, audits the exported pack, and installs only after the personal-use notice is accepted.

Build and audit success produce a candidate. In-game handling, controls, repeated use, and save/reload still require manual acceptance for each locomotive. Record observed results in the locomotive notes and keep unverified behavior marked as pending.

Changes to supported behavior should update the implementation, focused automated checks, README, and affected wiki pages together. Do not describe behavior as accepted without recorded in-game evidence.
